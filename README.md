# 주간 회의자료 자동 취합

Windows용 한/글 자동화(`pyhwpx`)와 Tkinter로 만든 생방기술2 주간 회의자료 취합 프로그램입니다. 지난주 최종본과 이번 주 취합 파일을 구분해서 선택하고, 업무 순서를 확인한 뒤 내장 양식으로 최종 HWP 파일을 만듭니다.

## 주요 기능

- **추진실적 이월:** 지난주 최종본의 추진계획에서 생방기술2 업무만 가져옵니다. 처음에는 지난주 순서로 표시하며, 이후 순서를 변경할 수 있습니다.
- **추진계획 취합:** 이번 주에 추가한 여러 HWP/HWPX 파일에서 추진계획을 가져옵니다.
- **업무 순서 변경:** 추진실적과 추진계획 모두 드래그, 위/아래 버튼, `Alt+↑/↓`로 조정합니다.
- **번호 정리:** 최종 순서에 따라 두 항목을 각각 1번부터 매깁니다. `1. 제목`처럼 점 뒤 공백은 한 칸으로 맞추고, 자동 번호와 직접 입력한 번호의 중복을 정리합니다.
- **날짜 선택:** 날짜 입력칸을 클릭하거나 달력 버튼을 눌러 선택합니다. 직접 입력도 가능하며 요일과 결과 파일명이 자동 갱신됩니다.
- **서식 유지:** 내장 양식의 제목·날짜·구분 제목을 사용하고, 업무의 표·그림과 본문의 내어쓰기·탭 정렬을 유지합니다.
- **최종 검사:** 문단 간격과 지정 스타일을 점검하고, 업무 순서·개수가 맞지 않으면 저장을 중단합니다.
- **PC용 화면:** 크기 조절과 스크롤을 지원합니다. Pretendard Medium 10pt, Windows 고해상도 인식, 무채색 화면과 블랙/화이트 강조를 적용했습니다. 보조 선택 표시에만 파스텔 블루를 사용합니다.
- **단일 EXE 배포:** 한글 양식과 글꼴을 EXE에 포함하므로 직원에게 별도 양식·글꼴 설치를 요청할 필요가 없습니다.

## 실행 환경

- Windows와 설치된 Windows용 한/글이 필요합니다. EXE에도 한/글 프로그램 자체가 포함되지는 않습니다.
- 소스 실행과 EXE 빌드는 Python이 필요합니다. 검증 환경은 **Python 3.14.4 / Tk 8.6.15**입니다.
- 직원이 배포된 EXE를 실행할 때는 Python 설치가 필요하지 않습니다.

```powershell
py -m pip install -r requirements.txt
py 업무보고_자동취합.py
```

## 사용 순서

1. **지난주 최종본**을 한 개 선택합니다.
2. **이번 주 취합 파일**을 추가합니다. 지난주 최종본은 이 목록에 다시 추가하지 않습니다.
3. **업무 제목 불러오기**를 누르고, 추진실적·추진계획의 내용을 확인합니다.
4. 각 탭에서 필요에 따라 업무 순서를 변경합니다.
5. 날짜를 달력에서 선택하거나 `2026.10.20.` / `2026-10-20` 형식으로 입력합니다.
6. 저장 폴더를 선택하고 **최종 회의자료 만들기**를 누릅니다.
7. 저장된 한글 문서를 열어 표·그림·페이지 배치를 확인합니다.

결과 이름은 입력 날짜에 따라 `생방기술국_회의자료_YYMMDD.hwp`로 정해집니다. 같은 이름의 파일이 있으면 다른 폴더를 선택하거나 기존 결과의 이름을 바꾼 뒤 실행합니다.

## 지난주 최종본의 부서 구분 기준

지난주 최종본에는 생방기술1 내용이 먼저, 생방기술2 내용이 그다음에 있습니다. 프로그램은 **추진계획 안의 `견학 및 기타 제작사항` 업무**를 생방기술1의 마지막 업무로 식별합니다.

- 이 업무의 본문과 표까지 제외하고, 그다음 번호가 붙은 업무부터 생방기술2 내용으로 가져옵니다.
- 경계 업무의 번호가 4번인지 6번인지에는 의존하지 않습니다.
- 추진실적에 같은 문구가 있어도 이월 기준으로 사용하지 않습니다.
- 경계 업무가 없거나 여러 개라서 구분이 모호하면 오류를 표시하고 중단합니다. 양식의 부서 구성이나 경계 제목이 바뀌면 추출 코드를 먼저 검토해야 합니다.

## EXE 만들기

먼저 소스 실행으로 수정 내용을 확인한 뒤 빌드합니다. 이전 EXE가 실행 중이면 파일 교체가 잠길 수 있으므로 해당 프로그램을 닫고 실행하세요.

```powershell
py build_exe.py
```

기본 결과 위치:

```text
dist/생방기술국_회의자료_취합.exe
```

`build_exe.py`는 내장 양식, 글꼴, 글꼴 라이선스, 고해상도 매니페스트를 사용합니다. 별도의 `테스트 파일` 폴더는 빌드 입력으로 포함하지 않습니다.

## 파일 구성

```text
업무보고_자동취합.py             GUI와 한글 문서 취합 처리
build_exe.py                    PyInstaller 빌드 스크립트
requirements.txt                검증한 패키지 버전
assets/report_template.hwpx      내장 한글 양식
assets/app.manifest             Windows 고해상도 설정
assets/fonts/                   Pretendard 글꼴과 라이선스
docs/CHANGELOG.md                구현 내용과 검증 기록
```

실제 회의자료, 개인 경로, EXE, 빌드 캐시와 백업 사본은 저장소 관리 대상에서 제외합니다.

## 글꼴

UI는 [Pretendard](https://github.com/orioncactus/pretendard) Regular·Medium·Bold를 사용합니다. 프로그램 프로세스 안에서만 등록하며 Windows의 시스템 글꼴 설정을 변경하지 않습니다. 글꼴은 SIL Open Font License 1.1로 제공되며 라이선스 전문은 [assets/fonts/OFL.txt](assets/fonts/OFL.txt)에 포함되어 있습니다.
